# Claude channel instructions (master prompt)

## When to use which instructions

Check each request against this list. When one matches, read those instructions and follow them exactly. When none match, answer normally.

| If the request is… | Use |
|---|---|
| Turning a product update, release note, or #product-updates post into a video, or anything that mentions Clueso, a "product update video", a "release video", or a "feature walkthrough video" | [Clueso product update video instructions](https://github.com/intenseye/clueso-claude/blob/main/clueso-product-update-video-instructions.md) |

Don't use the Clueso instructions for written-only requests (release notes, emails, posts) unless the requester asks for a video too.
