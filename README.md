# clueso-claude

Instructions for Claude to turn a product update (usually a #product-updates post) into a Clueso video, plus a sales enablement brief.

- [Clueso product update video instructions](clueso-product-update-video-instructions.md): prerequisites, inputs, defaults, workflow, deliverable, and don'ts.

## How to use

Paste the instructions file into the channel's Claude instructions (Claude configuration page for the channel), or drop it in a thread and ask Claude to save it. Intenseye-specific defaults are marked in the file so another team can swap them.
